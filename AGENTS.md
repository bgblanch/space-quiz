# Project rules

- Keep the quiz self-contained in `index.html`; do not add a server, build step, or dependencies.
- Preserve the existing visual style, responsive narrow layout, and light/dark theme support.
- Keep interactions accessible: semantic HTML, visible keyboard focus, keyboard operation, and reduced-motion support.
- Make small, focused changes and avoid unrelated edits.
- After behavior or UI changes, verify the quiz in the integrated browser, including relevant keyboard and results flows.
